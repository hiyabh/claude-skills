# ספר אצל מעצב (InDesign) - מה לבקש

כשמעצב מעמד את הספר, התפקיד שלנו הוא לתת לו את המפרט מבית הדפוס ולבדוק את מה שהוא מחזיר.

## מה לשלוח למעצב
- גודל חיתוך, שוליים, גלישה (אם יש תמונות עד הקצה), וכפולת העמודים (16 או 32 באופסט).
- לכריכה: את הפלט של `template.py`, כלומר התבנית בגודל מלא ואת קובץ המידות.
- **ספר עברי:** מסמך InDesign עם "Binding: Right to Left". אחרת העמודים הכפולים הפוכים.
- הנוסח המדויק של הכריכה מתוך המפרט, כדי שלא יוקלד מחדש עם שגיאות.

## הגדרות הייצוא לבקש
- PDF/X-1a:2001 או PDF/X-4, לפי בית הדפוס.
- פרופיל פלט: מה שבית הדפוס ביקש. בדרך כלל Coated FOGRA39 לכריכה, ו-Uncoated FOGRA29 או FOGRA47
  לנייר ספרים לא מצופה.
- Marks and Bleeds: גלישה 3 מ"מ. סימני חיתוך רק אם בית הדפוס רוצה אותם.
- עמודים בודדים ולא Spreads, אלא אם בית הדפוס ביקש אחרת.
- תמונות: לא לדחוס מתחת ל-300ppi.

## מה בודקים כשה-PDF חוזר
```
python scripts/prep_interior.py "<פנים>.pdf" "<פנים> - לדפוס.pdf" --printer offset [--has-bleed]
python scripts/check_interior.py "<פנים> - לדפוס.pdf" --expect <פנימי> <חיצוני> <עליון> <תחתון> --sheets
```
וכריכה שהמעצב בנה בעצמו: `check_cover.py` עם מפרט שמתאר אותה (גודל, שדרה, כריכה), ו-`--pdf` לקובץ שלו.
הבדיקה תאמת את המידות, את התיבות, את הגופנים, את הרזולוציה ואת המרכוז.
