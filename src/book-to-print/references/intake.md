# קליטה - מה לברר לפני שמתחילים

קודם קוראים מה שיש בתיקייה: קובץ Word, PDF, מייל או הצעת מחיר מבית הדפוס, שרטוט כריכה, ציור.
אחר כך שואלים **פעם אחת**, ב-AskUserQuestion אחד, רק מה שהקבצים לא עונים עליו.

## השאלות (לבחור רק את הפתוחות)

| נושא | מה שואלים | למה זה משנה |
|---|---|---|
| מצב הספר | Word גמור / PDF גמור / מעצב עם InDesign / עוד בכתיבה | קובע את מסלול הפנים (סעיף 3 ב-SKILL.md) |
| כריכה | קשה (בית דפוס וכריכייה) / רכה (בוקפוד או דפוס דיגיטלי) / שתיהן | קובע את הפריסה ואת השאלות לבית הדפוס |
| בית הדפוס | שם, ואם כבר יש הצעת מחיר או שרטוט | המספרים שלהם גוברים על כל ברירת מחדל |
| גודל דף | 14x21 / 17x24 / A5 / B5 / אחר | אחרי שהעימוד נקבע, שינוי גודל = עימוד מחדש |
| נייר | לבן או שמנת, 70/80/90 גרם, אם ידוע | קובע את רוחב השדרה |
| כמות | עשרות (דיגיטלי) / מאות ומעלה (אופסט) | דיגיטלי ואופסט שונים בגלישה, בצבע ובכפולת עמודים |
| מסת"ב | יש / צריך להוציא / לא צריך | ברקוד בגב. מסת"ב ישראלי מנפיקה הספרייה הלאומית |
| ציור הכריכה | שלו / של מעצב / AI / עוד אין | AI דורש מפתח API ועולה כסף |
| צבע הפנים | שחור-לבן / צבע | תמונות צבעוניות בספר שחור-לבן יודפסו באפור |

## ברירות מחדל כשאין תשובה
- כריכה רכה, 14x21, נייר לבן 80 גרם, למינציה מט. מסמנים כהערכה.
- ספר עברי: `direction: rtl`.
- בלי מסת"ב: אזור ברקוד ריק בגב, למקרה שיונפק.

## לפני שמתחילים לעבוד
- לוודא שהטקסט סופי. כל שינוי בטקסט אחרי העימוד מזיז עמודים, משנה את מספר העמודים ואת השדרה.
- לשאול אם ניקוד בפסוקים נשאר בדפוס. זה משנה גופן ומשנה עימוד.
- לשאול מה מופיע על הכריכה ומה **לא** מופיע (שם, תואר, תמונה). יש מחברים שלא רוצים את שמם על הכריכה.
