# מילון מונחים לדפוס

| מונח | באנגלית | מה זה |
|---|---|---|
| גודל חיתוך | trim | הגודל הסופי של הדף אחרי החיתוך. כל המידות נמדדות ממנו |
| גלישה | bleed | 3 מ"מ (בבוקפוד 3.2) של ציור מעבר לקו החיתוך, כדי שלא יישאר פס לבן אם החיתוך זז |
| אזור בטוח | safe area | 5-6 מ"מ פנימה מקו החיתוך. טקסט חשוב לא יוצא ממנו |
| שוליים פנימיים | inner / gutter | השוליים ליד השדרה. בספר עבה הם רחבים יותר, כי חלק מהדף נבלע בכריכה |
| שולי מראה | mirror margins | השוליים הפנימיים מתחלפים צד בין עמוד זוגי לאי-זוגי |
| עמוד אי-זוגי | recto | **בספר עברי הוא העמוד השמאלי** בספר הפתוח, והשדרה מימינו |
| קונטרס | signature | גיליון שמקופל ל-16 או 32 עמודים. באופסט מספר העמודים מתעגל לכפולה שלו |
| עובי גיליון | caliper | עובי דף אחד (שני עמודים) במ"מ. "80 גרם" יכול להיות 0.10 או 0.12, לפי סוג הנייר |
| שדרה | spine | עמודים חלקי 2 כפול עובי הגיליון. בכריכה קשה מוסיפים את עובי הקרטונים ומרווח |
| קרטון | board | הלוח הקשיח של כריכה קשה, מעט גדול מהדף |
| ביג | joint / hinge | הרווח בין הקרטון לשדרה, שבו הכריכה מתקפלת כשפותחים את הספר |
| גלישה מסביב לקרטון | turn-in / wrap | 15-20 מ"מ של כריכה שמתקפלים אל מאחורי הקרטון |
| פורזץ | endpaper | הדף שמודבק בין הכריכה לגוף הספר |
| CMYK | | ארבעת צבעי הדפוס. מסך עובד ב-RGB, ולכן צבע זוהר במסך יוצא עמום יותר בדפוס |
| פרופיל צבע | ICC | איך להמיר RGB ל-CMYK. בישראל נפוץ ISO Coated v2 (FOGRA39) לנייר כרומו, וגם FOGRA51 |
| שחור לטקסט | 100K | טקסט שחור קטן מודפס ב-K בלבד (0/0/0/100). "שחור עשיר" בארבעה צבעים מטשטש באותיות קטנות |
| כיסוי דיו | TAC | סך כל ארבעת הצבעים בנקודה. בדרך כלל עד 300%. פרופיל ההמרה דואג לזה |
| רזולוציה | dpi / ppi | 300 בגודל ההדפסה. תמונה מהאינטרנט היא בדרך כלל 72, והיא תצא מטושטשת |
| תיבת חיתוך ותיבת גלישה | TrimBox / BleedBox | שדות בתוך ה-PDF שאומרים למכונה איפה לחתוך |
| סימני חיתוך וקיפול | crop / fold marks | קווים דקים מחוץ לגלישה. בבוקפוד אסור לשים אותם |
| PDF/X-1a, PDF/X-4 | | תקני PDF לדפוס. יש בתי דפוס שדורשים אותם, ואז שואלים ומייצאים בהתאם |
| הטמעת גופנים | embedding | הגופן נשמר בתוך ה-PDF. גופן שלא הוטמע יוחלף בגופן אחר במכונה |
| עותק שמש / הדפסת ניסיון | proof | עותק אחד לפני הריצה. מגלה בעיות צבע, חיתוך ושוליים, ועולה מעט מאוד יחסית להדפסה חוזרת |
| למינציה | lamination | שכבת ניילון על הכריכה: מט או מבריקה |
| הטבעה | foil / emboss | זהב, כסף או בליטה. דורשים שכבה נפרדת בצבע ספוט, ונסגרים מול בית הדפוס |
