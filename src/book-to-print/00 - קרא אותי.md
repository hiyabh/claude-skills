# ספר לדפוס - סקיל ל-Claude Code

הסקיל הזה עוזר להוציא ספר לדפוס אמיתי: בעיקר את הכריכה (קשה או רכה), וגם את ההגדרות של פנים הספר.
הוא נבנה אחרי שהדפסנו סט של שלושה כרכים בכריכה קשה, וכל טעות שעשינו בדרך נכנסה אליו ככלל.

## מה הוא עושה
- **כריכה קשה** לפי השרטוט של הכריכייה: קרטון, ביג, גלישה ושדרה. **כריכה רכה** לבית דפוס או לבוקפוד.
- כל הכיתוב על הכריכה בגופן אמיתי וחד, ולא בתוך תמונה. בספר עברי החזית בצד הנכון.
- ציור הכריכה: שלך, של מעצב, או ציור שה-AI מייצר (צריך מפתח API).
- קובץ דפוס תקני: CMYK, גלישה, סימני חיתוך וקיפול, ברקוד למסת"ב.
- בדיקה אוטומטית: מידות, גופנים, רזולוציה, טקסט שיוצא מהאזור הבטוח, ציור שלא ממורכז.
- **פנים הספר:** הגדרות Word לספר עברי (גודל, שולי מראה בצד הנכון), ייצוא ל-PDF, ומדידה של מה שיצא.
- הדמיה של הספר הסגור, ומסמך הנחיות מסודר לבית הדפוס.

## התקנה (פעם אחת)
1. צריך **Claude Code** ו-**Python 3.10 ומעלה** (מ-python.org, לסמן "Add Python to PATH" בהתקנה).
2. הדרך הקלה: בדף של הסקיל במרכז הסקילים (https://hiyabh.github.io/claude-skills/) מעתיקים את שורת
   ההתקנה ומדביקים ל-Claude Code. הדרך הידנית: מעתיקים את התיקייה `book-to-print` כולה אל:
   `C:\Users\<שם המשתמש שלך>\.claude\skills\book-to-print`
3. פותחים את Claude Code וכותבים לו:
   **"תריץ את setup_check.py של הסקיל book-to-print"**
   הוא יתקין את מה שחסר, יוריד את פרופיל הצבע לדפוס, ויבנה כריכת ניסיון. בסוף צריך לראות "הכול מוכן".
   אם אתה רוצה ציור AI, תגיד לו להוסיף `--with-upscaler`.
4. ל-Word צריך Microsoft Word מותקן. בלעדיו הכריכות עדיין עובדות.

## איך מתחילים
פותחים את Claude Code בתיקייה של הספר וכותבים, למשל:
- "אני רוצה להוציא את הספר שלי לדפוס בכריכה קשה"
- "תכין לי כריכה רכה לבוקפוד"
- "בית הדפוס שלח שרטוט כריכה, תעדכן את הכריכה לפיו"
- "תבדוק שה-PDF של הספר מוכן לדפוס"

הוא ישאל כמה שאלות בהתחלה (גודל, נייר, בית דפוס, מאיפה הציור), ואחר כך יעבוד לבד ויראה לך תצוגות
לאישור.

## חשוב לדעת
- **המספרים של בית הדפוס קובעים.** עד שהם מגיעים, הסקיל עובד עם הערכות ומסמן אותן. כשבית הדפוס שולח
  שרטוט כריכה או עובי נייר, נותנים לו אותם והוא בונה מחדש.
- **תמיד עותק ניסיון** לפני ההדפסה המלאה.
- ציור AI עולה כסף בחשבון שלך, והסקיל יגיד לפני שהוא מייצר.
- הגופנים שבסקיל (Frank Ruhl Libre, Bellefair, Suez One) חופשיים גם לספר שנמכר. בגופן אחר כדאי לבדוק רישיון.
