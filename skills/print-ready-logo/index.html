לוגו מוכן להדפסה

הופך כל תמונה ללוגו שקוף באיכות גבוהה, ומייצא PNG ו-PDF מוכנים לבית דפוס

איך מתקינים הקבצים ב-GitHub

מה זה עושה

לוקח תמונה או לוגו - עם רקע לבן, רקע מורכב, או כבר שקוף - ומוציא ממנו שני קבצים: PNG עם רקע שקוף אמיתי, ו-PDF באיכות הדפסה שגם הוא שומר על השקיפות.

מזהה אוטומטית את מצב הרקע ובוחר אסטרטגיה: שומר שקיפות קיימת, מסיר רקע אחיד בפינות, או משתמש במודל AI לרקע מורכב. לאחר מכן מגדיל את התמונה בבינה מלאכותית (Real-ESRGAN) כדי לחדד קצוות וטקסט בלי לטשטש.

התוצאה: שני קבצים בשם עברי תיאורי, מוכנים לשליחה ישירה לבית דפוס.

מתי זה שימושי

  • לוגו ישן ברזולוציה נמוכה שצריך להגדיל לפני הדפסה על כרטיס ביקור או שילוט
  • הכנת לוגו עם רקע שקוף להדבקה על נייר מכתבים או מסמך
  • לוגו עם רקע לבן שצריך להפוך לשקוף לפני שימוש חוזר
  • יצוא PDF איכותי ללוגו לצורך שליחה למדפסת מקצועית

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תעשה רקע שקוף ללוגו הזה"
  • "תכין את הלוגו הזה להדפסה"
  • "תגדיל את הלוגו באיכות"
  • "PNG ו-PDF להדפסה מהתמונה הזו"

דוגמה

מה נותנים

logo.png - לוגו ישן, 425 פיקסלים, רקע לבן

מה מקבלים

לוגו - רקע שקוף.png (כ-1700 פיקסלים, שקוף) + לוגו - להדפסה.pdf, חדים עד כ-14 ס"מ ב-300 DPI

מה צריך שיהיה מותקן

מהלמה / הערה
Windows + כרטיס גרפי עם תמיכת Vulkanרוב המחשבים עם כרטיס גרפי מובנה או נפרד מהעשור האחרון תומכים בזה
הורדה אוטומטית של כלי ההגדלה בפעם הראשונהכ-45MB, חד-פעמי, דורש חיבור לאינטרנט
Python עם pillow, numpy, reportlab, opencv-pythonהתקנה: pip install pillow numpy reportlab opencv-python

לתשומת לבך: זו הגדלה חכמה, לא קסם - לוגו קטן מאוד יישאר מוגבל באיכות גם אחרי השבחה, ולגדלים גדולים מאוד (שילוט חוצות) עדיף מקור וקטורי אמיתי.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "לוגו מוכן להדפסה" (print-ready-logo).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/print-ready-logo.tar.gz
3. חלץ ממנה את התיקייה skills/print-ready-logo אל ~/.claude/skills/print-ready-logo. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Windows + כרטיס גרפי עם תמיכת Vulkan, הורדה אוטומטית של כלי ההגדלה בפעם הראשונה, Python עם pillow, numpy, reportlab, opencv-python. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תעשה רקע שקוף ללוגו הזה".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- print-ready-logo

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
