מדריך ארכיטקטורה

קלוד לומד את מבנה הפרויקט שלך פעם אחת, ואז בונה קוד חדש בדיוק באותו סגנון.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

במקום שקלוד ינחש איך לבנות קובץ חדש, הסקיל שומר לכל פרויקט מסמך אחד עם ההחלטות שכבר התקבלו: איך מסודרות התיקיות, איך קוראים לקבצים, איזו ספריית עיצוב בשימוש, איך מטפלים בשגיאות ועוד - עם דוגמאות קוד אמיתיות, לא רק הסברים.

בפעם הראשונה שעובדים על פרויקט, קלוד סורק את הקוד הקיים (אם יש), שואל כמה שאלות על ההעדפות שלך, וכותב את כל זה למסמך ייעודי. מאותו רגע, כל קוד חדש שנכתב עובר קודם דרך המסמך הזה.

כשאתה אומר באמצע עבודה 'תמיד תעשה ככה' או 'אני מעדיף X על פני Y' - קלוד מוסיף את זה מיד למסמך, כדי שהכלל יישמר גם בשיחות הבאות.

מתי זה שימושי

  • מתחילים פרויקט קוד חדש וקלוד צריך להחליט על מוסכמות שמירה, שמות ומבנה תיקיות
  • פרויקט קיים בלי תיעוד - וקלוד כל פעם 'ממציא' סגנון קצת שונה
  • אתה מעדיף גישה מסוימת (Tailwind ולא CSS Modules, Zustand ולא Redux) ורוצה שזה יישמר קבוע
  • צריך לתעד 'טעם עיצובי' - מינימליזם מול עושר פיצ'רים, מובייל-קודם וכו'

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תגדיר ארכיטקטורה לפרויקט הזה"
  • "תמיד תשתמש ב-X בפרויקט הזה"
  • "מה המוסכמות של הפרויקט הזה?"
  • "אני מעדיף X על פני Y"

מה צריך שיהיה מותקן

שום דבר מעבר ל-Claude Code עצמו.

לתשומת לבך: המסמך שנוצר משרת רק את הפרויקט הספציפי שבו נכתב - לכל פרויקט צריך קובץ משלו.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "מדריך ארכיטקטורה" (project-architecture).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/project-architecture.tar.gz
3. חלץ ממנה את התיקייה skills/project-architecture אל ~/.claude/skills/project-architecture. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. ודא שהקובץ SKILL.md נמצא בתיקייה.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תגדיר ארכיטקטורה לפרויקט הזה".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- project-architecture

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
