תכנון לפני בנייה

עוצר לפני שורת קוד ראשונה - PRD, אילוצים ותוכנית מאושרת - כדי לא לבנות דבר לא נכון.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

לפני פרויקט חדש או פיצ'ר משמעותי, הסקיל מריץ ראיון מובנה (PRD): מה בונים, למי, אילו תרחישי שימוש, ומה בכוונה נשאר מחוץ ל-scope.

כותב קובץ אילוצים שליליים עם חלופה לכל אילוץ ('אל תעשה X - תעשה Y במקום, כי Z'), כותב טסטים ראשוניים מתוך ה-PRD בלבד (בלי להסתכל על קוד קיים), ובונה תוכנית מימוש מפורטת.

אסור לכתוב קוד לפני שהמשתמש אישר את התוכנית במפורש - יש לולאת משוב שבה מוסיפים הערות inline עד שהיא מאושרת. בסוף נשארים גם קבצי מעקב התקדמות ותיעוד טעויות לכל אורך הפרויקט.

מתי זה שימושי

  • מתחילים פרויקט חדש מאפס (אתר, אפליקציה, API)
  • מוסיפים פיצ'ר גדול שנוגע בכמה קבצים והחלטות ארכיטקטורה
  • רוצים למנוע מצב שבו הסוכן בונה משהו שלא בדיוק מה שביקשתם
  • צריך תיעוד PRD ותוכנית שאפשר להעביר לצוות אחר

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "אני רוצה לבנות אפליקציה חדשה ל..."
  • "בואו נתכנן פיצ'ר משמעותי לפני שמתחילים"
  • "פרויקט חדש - תעשה קודם ראיון דרישות"
  • "תכין PRD ותוכנית לפני שאתה נוגע בקוד"

דוגמה

מה נותנים

"אני רוצה לבנות מערכת ניהול מלאי לחנות קטנה"

מה מקבלים

סדרת שאלות ממוקדות, ואז docs/PRD.md מלא, docs/constraints.md עם חלופות, טסטים ראשוניים, ו-docs/plan.md שממתין לאישור שורה-שורה לפני שנכתבת שורת קוד אחת.

מה צריך שיהיה מותקן

שום דבר מעבר ל-Claude Code עצמו.

לתשומת לבך: מתאים לפרויקטים ופיצ'רים משמעותיים בלבד - לתיקון באג, refactor קטן או סקריפט חד-פעמי הוא מיותר ומאט.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "תכנון לפני בנייה" (pre-build-setup).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/pre-build-setup.tar.gz
3. חלץ ממנה את התיקייה skills/pre-build-setup אל ~/.claude/skills/pre-build-setup. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. ודא שהקובץ SKILL.md נמצא בתיקייה.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "אני רוצה לבנות אפליקציה חדשה ל...".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- pre-build-setup

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
