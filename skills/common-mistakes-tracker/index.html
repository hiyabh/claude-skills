מעקב טעויות נפוצות

כל תיקון שאתה נותן לקלוד נשמר, כדי שהוא לא יחזור על אותה טעות בפעם הבאה.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

הסקיל שומר יומן טעויות לכל טכנולוגיה ופרויקט. כשאתה מתקן את קלוד, או שהוא מזהה שגיאה שהוא עצמו גרם לה, הטעות נרשמת עם: מה קרה, מה הגישה הנכונה, ובאיזה הקשר זה קורה.

בתחילת כל משימת קידוד, קלוד קורא את היומן ומסנן לפי הטכנולוגיה הרלוונטית - כך שהוא נכנס לעבודה כשהוא כבר 'זוכר' מה לא לעשות, במקום לגלות את זה שוב על בשרו.

זה מבוסס על שיטת עבודה פנימית של Anthropic: לתת למודל 'איזור טעויות נפוצות' לקרוא לפני שהוא מתחיל לעבוד.

מתי זה שימושי

  • קלוד עשה טעות טכנית וקיבל תיקון ממך - כדאי שזה יירשם כדי שלא יחזור
  • יש לך הרגלי Git או דפוסי קוד ספציפיים שקלוד ממשיך 'לשכוח'
  • עובדים הרבה עם טכנולוגיה מסוימת (React, Python וכו') ורוצים שכל המלכודות המוכרות יישמרו במקום אחד
  • רוצים שקלוד יבדוק אוטומטית לפני שהוא כותב קוד אם הוא עומד לחזור על טעות ידועה

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תזכור את הטעות הזאת"
  • "אל תעשה את זה שוב"
  • "תוסיף את זה ליומן הטעויות"
  • "בדוק ביומן הטעויות לפני שאתה מתחיל"

מה צריך שיהיה מותקן

שום דבר מעבר ל-Claude Code עצמו.

לתשומת לבך: היומן מתחיל ריק - הערך שלו נבנה בהדרגה ככל שמצטברות יותר טעויות מתועדות.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "מעקב טעויות נפוצות" (common-mistakes-tracker).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/common-mistakes-tracker.tar.gz
3. חלץ ממנה את התיקייה skills/common-mistakes-tracker אל ~/.claude/skills/common-mistakes-tracker. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. ודא שהקובץ SKILL.md נמצא בתיקייה.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תזכור את הטעות הזאת".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- common-mistakes-tracker

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
