דיבאג שיטתי

מוצא את שורש הבעיה במקום לתקן סימפטומים - עם הוכחה שהתיקון באמת עובד.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

כשמשהו נשבר - טסט נכשל, שגיאה בפרודקשן, או שגיאת בנייה (build) - הסקיל לא מנחש. הוא קודם משחזר את התקלה ומוכיח אותה, ורק אז מחפש את הסיבה האמיתית.

התהליך: שחזור התקלה, איתור השורש (לא רק הסימפטום), תיקון מינימלי וממוקד, ואז הרצה חוזרת שמוכיחה שהתיקון עבד ושלא נשבר שום דבר אחר.

מקבלים: הסבר בעברית של הסיבה האמיתית לבעיה, תיאור התיקון, וההוכחה - לפני התיקון (כישלון) ואחריו (הצלחה).

מתי זה שימושי

  • טסט אוטומטי נכשל ולא ברור למה
  • משתמשים מדווחים על שגיאות בפרודקשן וצריך לאתר את הגורם
  • ה-build נשבר אחרי שינוי ואין זמן לחפור לבד
  • יש חשד לבאג שחוזר על עצמו במקומות שונים בקוד

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "הטסט הזה נכשל, תמצא למה ותתקן"
  • "יש שגיאות 500 בעמוד התשלום, תחקור"
  • "תתקן את שגיאת ה-build מהשורש ותוודא שהיא נפתרה"
  • "למה זה נשבר?"

דוגמה

מה נותנים

"הטסט checkout.test.ts נכשל, תבין למה ותתקן"

מה מקבלים

דוח קצר: הסיבה האמיתית לכישלון, השורה שתוקנה, והרצה חוזרת שמראה טסט ירוק וכל שאר הטסטים עדיין עוברים.

מה צריך שיהיה מותקן

מהלמה / הערה
גישה להרצת טסטים/build של הפרויקטכדי שהסקיל יוכל לשחזר את התקלה ולאמת את התיקון בפועל, לא רק לנחש

לתשומת לבך: לפעמים השחזור דורש פרטים נוספים (סביבה, קלט מדויק) - אם אי אפשר לשחזר, הסקיל עוצר ושואל במקום לנחש.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "דיבאג שיטתי" (debug).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/debug.tar.gz
3. חלץ ממנה את התיקייה skills/debug אל ~/.claude/skills/debug. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: גישה להרצת טסטים/build של הפרויקט. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "הטסט הזה נכשל, תמצא למה ותתקן".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- debug

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
