ספר דיגיטלי לדפדוף

הופך PDF לאתר שמדפדפים בו כמו בספר אמיתי, עם קישור מוכן לשיתוף

איך מתקינים הקבצים ב-GitHub

מה זה עושה

לוקח קובץ PDF (או קישור לצפיין flipbook קיים כמו heyzine) ובונה ממנו אתר סטטי עצמאי שבו כל עמוד נהפך בעזרת אנימציה שנראית כמו דפדוף בספר אמיתי.

התמיכה בעברית מובנית כברירת מחדל - כריכה מימין, דפדוף מימין לשמאל, וכל עמוד נשאר קריא כרגיל. יש זום, מסך מלא, תמונות ממוזערות לניווט מהיר, וניווט מקלדת.

בסיום מפרסם את האתר לקישור ציבורי דרך Vercel, כך שאפשר לשלוח לינק אחד ולכל אחד יש גישה מיידית לספר.

מתי זה שימושי

  • קטלוג או חוברת שרוצים לשתף כלינק במקום קובץ PDF להורדה
  • ספר או חוברת לילדים שרוצים להציג בצורה אינטראקטיבית
  • מגזין או ידיעון תקופתי שצריך גרסת דפדוף נוחה
  • הפיכת ספר שכבר קיים כ-flipbook בשירות חיצוני לאתר עצמאי

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תבנה לי אתר לדפדף בקובץ ה-PDF הזה"
  • "תהפוך את ה-PDF הזה לספר דיגיטלי"
  • "אני רוצה אתר flipbook מהחוברת הזו"
  • "דפדוף כמו ספר מה-PDF שצירפתי"

מהלמה / הערה

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "ספר דיגיטלי לדפדוף" (pdf-flipbook).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/pdf-flipbook.tar.gz
3. חלץ ממנה את התיקייה skills/pdf-flipbook אל ~/.claude/skills/pdf-flipbook. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Python עם pymupdf ו-pillow, חשבון Vercel (יש חינמי), קובץ PDF מקור. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תבנה לי אתר לדפדף בקובץ ה-PDF הזה".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- pdf-flipbook

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
