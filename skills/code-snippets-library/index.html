ספריית קטעי קוד

קטעי קוד שהוכחו כעובדים נשמרים במקום אחד, כדי שקלוד ישתמש בהם שוב במקום להמציא מחדש.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

במקום שקלוד יכתוב כל פעם מחדש קוד סטנדרטי (middleware, hook נפוץ, קונפיג), הסקיל שומר קטעי קוד מוכחים בתיקיות לפי קטגוריה - React, Python, TypeScript, CSS, API, RTL עברי ועוד.

לכל קטע קוד יש קובץ עם תיאור, הקוד עצמו, דוגמת שימוש והערות/מלכודות - וכל הקטעים מאונדקסים בקובץ אחד עם תגיות לחיפוש מהיר.

לפני שקלוד כותב קוד סטנדרטי, הוא בודק אם כבר יש קטע מתאים בספריה, ומתאים אותו להקשר הנוכחי - לא מעתיק בעיוורון.

מתי זה שימושי

  • כתבת קטע קוד טוב (middleware, hook, פונקציית עזר) ורוצה שישמש שוב בפרויקטים אחרים
  • יש לך תבניות קונפיג קבועות (tsconfig, vite.config) שחוזרות בכל פרויקט
  • עובד הרבה עם RTL עברי ורוצה ספריית פתרונות ייעודית לזה
  • רוצה שקלוד יבדוק אוטומטית אם יש כבר פתרון מוכן לפני שהוא כותב boilerplate

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "שמור את הקוד הזה כ-snippet"
  • "תוסיף את זה לספריה"
  • "תראה לי מה יש לי בספריית הקטעים"
  • "יש לי snippet מוכן ל-X?"

דוגמה

מה מקבלים

נוצר קובץ snippets/api/auth-middleware.md עם הקוד, תיאור ותגיות, ונרשם באינדקס לחיפוש עתידי

מה צריך שיהיה מותקן

שום דבר מעבר ל-Claude Code עצמו.

לתשומת לבך: הספריה מתחילה ריקה - הערך שלה נבנה ככל שנשמרים בה יותר קטעים מוכחים מתוך הפרויקטים שלך.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "ספריית קטעי קוד" (code-snippets-library).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/code-snippets-library.tar.gz
3. חלץ ממנה את התיקייה skills/code-snippets-library אל ~/.claude/skills/code-snippets-library. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. ודא שהקובץ SKILL.md נמצא בתיקייה.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "שמור את הקוד הזה כ-snippet".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- code-snippets-library

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
