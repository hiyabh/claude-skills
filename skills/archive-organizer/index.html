ארגון ארכיון קבצים

הופך ערימה של אלפי קבצים מפוזרים לתיקיות מסודרות - בלי למחוק ובלי לפספס קובץ.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

הסקיל לוקח תיקייה עמוסה בלי שום סדר - מיילים מיוצאים, מסמכים, קבצים ישנים - ומארגן אותה בשלבים: קודם סורק ומדווח מה יש בפועל (סוגי קבצים, דפוסי שמות, כמה יש מכל סוג), אחר כך מציע מבנה תיקיות ומחכה לאישור, ורק אז מתחיל להעביר קבצים לפי כללי מיון שנבנים בהדרגה מתוך מה שנמצא בפועל.

העיקרון המרכזי: שום דבר לא נמחק. קבצים שנראים כמו זבל (הודעות מערכת, קבצים זמניים, כפילויות) עוברים ל'תיקיית הסגר' לבדיקה ידנית, לא נעלמים. כל הרצה כוללת מצב 'בדיקה יבשה' שמראה מה יזוז לפני שמזיזים בפועל, וכל פעולה נרשמת ביומן טקסט.

בסוף התהליך מקבלים: מבנה תיקיות ממוספר וברור, קבצים עם שמות נקיים (תאריך + נושא במקום קידומות טכניות), תיקיית 'לסיווג' לקבצים שלא זוהו אוטומטית, ותיקיית הסגר נפרדת לזבל - הכל ניתן לשחזור ולבדיקה חוזרת.

מתי זה שימושי

  • תיקיית מיילים מיוצאת עם אלפי קבצי pdf/msg/eml בלי שום מיון
  • ארכיון משפחתי או ארגוני ישן שהצטבר במשך שנים בלי מבנה
  • תיקיית הורדות שדורשת ניקוי מקבצים כפולים וזמניים
  • ארכיון מחקר או פרויקט עם מאות קבצים שצריך לחלק לקטגוריות
  • מעבר בין מחשבים או גיבוי ישן שצריך לסדר לפני העברה

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תעזור לי לארגן תיקייה עם אלפי קבצים"
  • "סדר לי את הארכיב הזה לפי קטגוריות"
  • "יש לי תיקיית הורדות מבולגנת, תנקה אותה"
  • "תמיין את קבצי המייל האלה ותמצא כפילויות"

דוגמה

מה נותנים

תארגן לי את תיקיית הארכיון שלי, יש בה בערך 8,000 קבצים בלי שום סדר

מה מקבלים

סריקה ראשונית מראה 8,000 קבצים - בעיקר pdf ו-docx, עם דפוסי שם חוזרים. מוצע מבנה של 5 קטגוריות + תיקיית הסגר, ולאחר אישור מתבצע מיון בכמה סבבים עד שנשארים רק קבצים שדורשים בדיקה ידנית

מה צריך שיהיה מותקן

מהלמה / הערה
Python 3.8 ומעלהמותקן במחשב וזמין מהטרמינל (בדוק עם py --version או python --version)
גישת קריאה/כתיבה לתיקיית הארכיוןהסקריפטים מזיזים קבצים בתוך התיקייה עצמה, לא מעתיקים אותם החוצה

לתשומת לבך: המיון מתבסס בעיקר על שם הקובץ ולא על תוכנו (כדי להישאר מהיר גם על אלפי קבצים), כך שקבצים עם שמות לא אינפורמטיביים ייפלו לתיקיית סיווג ידני במקום להתמיין אוטומטית.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "ארגון ארכיון קבצים" (archive-organizer).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/archive-organizer.tar.gz
3. חלץ ממנה את התיקייה skills/archive-organizer אל ~/.claude/skills/archive-organizer. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Python 3.8 ומעלה, גישת קריאה/כתיבה לתיקיית הארכיון. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תעזור לי לארגן תיקייה עם אלפי קבצים".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- archive-organizer

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
