עריכת תמלול נאמנה

הופך תמלול גולמי של שיחה או ראיון למסמך קריא - בלי לקצר או לשנות מילה אחת

איך מתקינים הקבצים ב-GitHub

מה זה עושה

מקבל תמלול אוטומטי גולמי (עם חותמות זמן, גמגומים ושיבושים) של שיחה, ראיון, פאנל או דיון - ומפיק ממנו מסמך עברי קריא וזורם, בלי לסכם ובלי לקצר.

כל דובר נשאר בגוף ראשון שלו, עם תווית דובר מודגשת בכל מעבר. מתקן פיסוק וחלוקה לפסקאות, מסיר חותמות זמן וגמגומים, ומוסיף כותרות נושא קלות שמארגנות את הקריאה בלי לגעת בתוכן עצמו.

פסוקים שצוטטו במהלך השיחה משוחזרים לנוסח המדויק עם ניקוד ומקור. התוצר הסופי הוא קובץ Word בעברית מלאה מימין לשמאל, מוכן להדפסה או שיתוף.

מתי זה שימושי

  • תמלול ריאיון או פודקאסט שרוצים להפוך למאמר קריא בלי לאבד אף פרט
  • פאנל או דיון עם כמה דוברים שצריך לתעד במדויק, כל אחד בקולו שלו
  • שיעור שאלות-ותשובות שהוקלט ותומלל אוטומטית
  • כל תמלול עם חותמות זמן ושיבושי מכונה שצריך להפוך למסמך מקצועי

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "עריכה קוהרנטית של התמלול הזה"
  • "ערוך לי את תמלול הראיון"
  • "תהפוך את התמלול הזה לכתבה בלי לקצר כלום"
  • "כל מילה ככתבה וכלשונה"

דוגמה

מה נותנים

תמלול גולמי: '0:06 אז... תשמע, אני חושב ש... 1:09 כן בדיוק, זה מה שקרה'

מה מקבלים

מסמך Word ערוך: **המנחה:** תשמע, אני חושב ש... **אורח:** כן, בדיוק זה מה שקרה.

מה צריך שיהיה מותקן

מהלמה / הערה
Python 3.9+ עם python-docxהתקנה: pip install python-docx
קובץ תמלול קלטDOCX / TXT / SRT / VTT
Microsoft Wordרק אם מבקשים הדפסה ישירה בסוף התהליך; בניית הקובץ עצמה לא דורשת Word

לתשומת לבך: תמלול ארוך מאוד (כמה שעות) עלול לדרוש כמה הודעות רצופות כדי להשלים את העריכה בלי לדלג על נושא - זה תקין, לא סימן לבעיה.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "עריכת תמלול נאמנה" (coherent-transcript-editor).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/coherent-transcript-editor.tar.gz
3. חלץ ממנה את התיקייה skills/coherent-transcript-editor אל ~/.claude/skills/coherent-transcript-editor. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Python 3.9+ עם python-docx, קובץ תמלול קלט, Microsoft Word. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "עריכה קוהרנטית של התמלול הזה".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- coherent-transcript-editor

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
