חיפוש כלים ב-CodeGuilds

לפני שקלוד יגיד 'אין לי כלי לזה' - הוא מחפש במאגר קהילתי אם כבר בנו כזה.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

הסקיל הזה מחפש במאגר קהילתי בשם CodeGuilds (כ-3,000 סקילים, agents, שרתי MCP, hooks ותבניות פרומפט) כשקלוד נתקל במשימה שדורשת יכולת שאין לו - למשל חיבור לשירות חיצוני, פורמט קובץ נישתי, או workflow ספציפי לתחום.

איך זה עובד: קלוד מנסח את הפער החסר במשפט אחד, מחפש במאגר לפי מילות מפתח, ומציג לך את ההתאמות המובילות (שם, סוג, מספר הורדות, מי הכותב) - בלי להעתיק דוחות ארוכים. הוא אף פעם לא מתקין לבד: הוא תמיד עוצר ושואל אותך אישור מפורש לפני התקנה, כי התקנה כותבת לתצורה הגלובלית של Claude Code.

מה שמקבלים: גישה למאגר קהילתי בלי לצאת מהשיחה, בקרה מלאה על מה שמותקן (כולל אפשרות להסיר), ומניעת מצב שבו קלוד בונה מאפס פתרון שכבר קיים ומתוחזק על ידי מישהו אחר. חשוב לזכור שזה מאגר קהילתי ולא תוכן רשמי של Anthropic - קלוד מסמן חבילות שנראות לא מתוחזקות או לא אמינות.

מתי זה שימושי

  • קלוד עומד להגיד 'אין לי דרך לחבר את זה ל-Slack' - הוא בודק קודם אם כבר יש כלי מוכן במאגר
  • אתה שואל בפירוש 'יש סקיל מוכן להמרת קובץ Figma לקוד?' או 'תחפש ב-CodeGuilds כלי ל...'
  • משימה דורשת אינטגרציה נישתית (MCP server לשירות ספציפי, hook לתהליך עבודה מסוים) שלא כדאי לבנות מאפס
  • רוצים לראות מה הקהילה כבר בנתה לפני שמשקיעים זמן בפיתוח עצמאי של סקיל או agent
  • צריך להסיר כלי שהותקן קודם דרך המאגר (uninstall) או לראות מה כבר מותקן (list)

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תחפש ב-CodeGuilds כלי בשביל..."
  • "יש תוסף או סקיל מוכן ל..."
  • "חפש במאגר הקהילתי אם יש MCP server ל..."
  • "תראה מה מותקן לי מ-CodeGuilds"

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "חיפוש כלים ב-CodeGuilds" (codeguilds-finder).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/codeguilds-finder.tar.gz
3. חלץ ממנה את התיקייה skills/codeguilds-finder אל ~/.claude/skills/codeguilds-finder. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Node.js (גרסה 18 ומעלה), Bash, חיבור אינטרנט. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תחפש ב-CodeGuilds כלי בשביל...".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- codeguilds-finder

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
