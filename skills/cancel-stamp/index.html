חותמת ביטול

מטביע קווים אלכסוניים עם כיתוב 'בוטל' על DOCX או PDF, בלי לגעת במילה אחת בטקסט

איך מתקינים הקבצים ב-GitHub

מה זה עושה

מוסיף שכבת ביטול שקופה-למחצה מעל מסמך קיים - שני קווים מקבילים באלכסון עם כיתוב ביניהם, או צורת X עם כיתוב במרכז - בלי לשנות שום תו בטקסט המקורי.

עובד גם על מסמכי Word וגם על PDF, כולל מסמכים עם רקע נייר-מכתבים מלא-עמוד (letterhead) - החותמת תמיד מונחת מעל הטקסט כך שהיא נראית, גם כשהרקע אטום.

לפני השמירה הסקריפט בודק שהטקסט של המסמך לא השתנה בכלל, ונכשל בלי לשמור אם כן - אז אין סיכון לפגיעה בתוכן.

מתי זה שימושי

  • מכתב שנשלח בטעות או שהוחלט לא לשלוח
  • טיוטת חוזה שבוטלה והוחלפה בגרסה חדשה
  • מסמך רשמי שצריך לסמן כ-DRAFT או VOID לפני שמירה בארכיון
  • הסכם שבוטל עקב שינוי נסיבות, כשרוצים לשמור את הגרסה המקורית מסומנת

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תוסיף חותמת ביטול למסמך הזה"
  • "תסמן את המסמך הזה כמבוטל"
  • "קווים מקבילים עם טקסט באלכסון"
  • "תוסיף חותמת VOID על ה-PDF"

דוגמה

מה נותנים

מכתב.docx חתום ומוכן

מה מקבלים

מכתב.docx עם קווים אלכסוניים עמומים וכיתוב 'בוטל - לא נשלח' מעל הטקסט, שהטקסט עצמו נשאר קריא מתחת

מה צריך שיהיה מותקן

מהלמה / הערה
Python עם Pillow, PyMuPDF, python-docxהתקנה: pip install pillow pymupdf python-docx
Windows + Microsoft Wordנדרש רק לביטול DOCX רב-עמודים (עימוד עמודים דרך Word); PDF עובד בכל מערכת הפעלה
גופן TTF שמכסה את שפת הכיתובברירת המחדל היא גופן מודגש של Windows

לתשומת לבך: טקסט אלכסוני מיושר בסדר חזותי בלבד (בלי מנוע bidi מלא) - מתאים לשורת חותמת קצרה עם תאריך או קוד, לא לפסקה ארוכה.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "חותמת ביטול" (cancel-stamp).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/cancel-stamp.tar.gz
3. חלץ ממנה את התיקייה skills/cancel-stamp אל ~/.claude/skills/cancel-stamp. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Python עם Pillow, PyMuPDF, python-docx, Windows + Microsoft Word, גופן TTF שמכסה את שפת הכיתוב. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תוסיף חותמת ביטול למסמך הזה".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- cancel-stamp

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
