תלת-מימד חי

כל נושא הופך לסצנה תלת-ממדית שמסובבים, מגדילים ומשחקים בה - עם מחוונים, ניגון והאצה - כדף אחד לשיתוף

איך מתקינים הקבצים ב-GitHub

מה זה עושה

מבקשים מקלוד להמחיש משהו בתלת-מימד: מטוס שממריא ונוחת, מערכת השמש, מנוע בוכנה, גל שמתפשט. קלוד בונה סצנה ב-Three.js ומפרסם אותה כדף חי (Artifact). את הסצנה גוררים כדי לסובב אותה וצובטים כדי להגדיל.

מתחת לסצנה יש לוח בקרה בעברית מימין לשמאל: ניגון והשהיה, ציר זמן, כפתורי מהירות (×1 עד ×8), מחוונים ומתגים לפרמטרים החשובים, וקריאות חיות כמו גובה, מהירות או זווית. הסצנה בנויה ביחידות אמיתיות ובפרופורציות אמיתיות, וזה מה שגורם לה להרגיש נכונה.

קלוד כותב רק את קובץ הסצנה, ותבנית קבועה דואגת למנוע, ללוח ולמצב בהיר וכהה. לפני המסירה הוא פותח את הדף בדפדפן, בודק שהסצנה מצוירת ושאין שגיאות, ורק אז שולח קישור.

מתי זה שימושי

  • הסבר ויזואלי לילדים או לתלמידים: איך עובד ירח מלא, למה יש עונות
  • סימולטור קטן: המראה של מטוס, מסלול של לוויין, נפילה חופשית עם התנגדות אוויר
  • מודל של מוצר או מבנה שרוצים לסובב ולהציג למישהו בקישור
  • השוואה בין פרמטרים: מזיזים מחוון ורואים מיד מה משתנה

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תמחיש לי בתלת-מימד איך ירח מקיף את כדור הארץ"
  • "תבנה לי סימולטור של מטוס שממריא ונוחת"
  • "תראה לי בתלת-מימד איך עובד מנוע בוכנה"
  • "סצנה תלת-ממדית של מערכת השמש עם מחוון מהירות"

דוגמה

מה נותנים

תמחיש לי בתלת-מימד המראה, הקפה ונחיתה של F-16, עם מצערת ושקיעה

מה מקבלים

קישור לדף שבו F-16 ממריא, מטה כנפיים בזווית הנכונה, מקיף את המסלול ונוחת על רקע שקיעה. בלוח: מחוון מצערת, מתג מבער אחורי, מהירות ×1 עד ×8, וקריאות חיות של גובה, מהירות וזווית הטיה

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "תלת-מימד חי" (threejs-viewer).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/threejs-viewer.tar.gz
3. חלץ ממנה את התיקייה skills/threejs-viewer אל ~/.claude/skills/threejs-viewer. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: Claude Code עם כלי Artifact, Python 3 ו-Node.js, Playwright (לא חובה). אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תמחיש לי בתלת-מימד איך ירח מקיף את כדור הארץ".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- threejs-viewer

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
