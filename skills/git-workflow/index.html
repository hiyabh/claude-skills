עבודת Git מקצה לקצה

פותר קונפליקטים עם תיעוד החלטות, כותב הודעות commit מקצועיות, ובונה pipeline של CI/CD.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

שלושה תהליכי Git שקלוד מבצע בעצמו מקצה לקצה (בלי להחזיר פקודה למשתמש): פתרון קונפליקטים ב-merge/rebase, כתיבת הודעת commit מהדיף האמיתי, ובניית תסריט (workflow) ל-GitHub Actions.

בפתרון קונפליקטים - מבין את הכוונה של שני הצדדים לפני שמכריע, שומר על שתי הכוונות כשהן לא סותרות, ותמיד מריץ build וטסטים אחרי כדי לוודא שה'פתרון' באמת עובד.

הודעות commit נכתבות בפורמט מקובל (Conventional Commits) מתוך הדיף עצמו - לא ניחוש - וה-CI/CD נבנה לפי הפרויקט האמיתי (שפה, כלי בדיקה, יעד דיפלוי), כולל רשימת secrets שצריך להוסיף ידנית.

מתי זה שימושי

  • יש קונפליקט ב-merge/rebase ורוצים שיפתר עם הסבר מה נשמר מכל צד
  • רוצים הודעת commit מקצועית שמסכמת נכון את השינוי בפועל
  • צריך pipeline של GitHub Actions שמריץ טסטים, בונה ומפרסם ל-staging
  • עובדים בענף משותף ורוצים למנוע טעויות מיזוג

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תפתור את קונפליקטי המיזוג ותסביר מה שמרת מכל צד"
  • "תעשה commit עם הודעה שמסכמת מה עשיתי"
  • "תכתוב workflow ל-GitHub Actions שמריץ טסטים ומפרסם ל-staging"
  • "CI/CD לפרויקט הזה"

דוגמה

מה נותנים

"תכתוב GitHub Actions workflow שמריץ טסטים, בונה ומפרסם ל-staging בכל push ל-develop"

מה מקבלים

קובץ .github/workflows מוכן עם שלבים מקושרים (test -> build -> deploy), caching, ורשימת secrets שצריך להוסיף בהגדרות הריפו.

מה צריך שיהיה מותקן

שום דבר מעבר ל-Claude Code עצמו.

לתשומת לבך: פעולות הרסניות כמו push --force לענף משותף תמיד מסומנות לאישור מפורש - הסקיל לא מבצע אותן על דעת עצמו.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "עבודת Git מקצה לקצה" (git-workflow).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/git-workflow.tar.gz
3. חלץ ממנה את התיקייה skills/git-workflow אל ~/.claude/skills/git-workflow. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. ודא שהקובץ SKILL.md נמצא בתיקייה.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תפתור את קונפליקטי המיזוג ותסביר מה שמרת מכל צד".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- git-workflow

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
