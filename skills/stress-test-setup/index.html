בדיקות עומס

בונה בדיקות עומס (k6) - עומס רגיל, זינוק פתאומי ועומס ממושך - לפי נפח המשתמשים הצפוי.

איך מתקינים הקבצים ב-GitHub

מה זה עושה

מתאים לאפליקציות/API שרצים בפרודקשן עם משתמשים אמיתיים או SLA. שולף את נפח העומס הצפוי (בקשות בשנייה, משתמשים במקביל) ובונה שלוש בדיקות k6: עומס בסיסי, זינוק פתאומי (spike) ועומס ממושך לאיתור דליפות זיכרון (soak).

לפני כתיבת הקוד, עובר על נקודות חנק צפויות (מסד נתונים, קריאות חיצוניות), נפילה בחן, הגבלת קצב (rate limiting) ו-caching - ומתעד הכל בתוכנית סקלביליות.

מוסיף את הבדיקות לתסריטי ההרצה של הפרויקט, עם סף כשלון ברור (זמן תגובה, אחוז שגיאות) שנשלף מדרישות המוצר בפועל - לא ברירת מחדל שרירותית.

מתי זה שימושי

  • אפליקציית web/API שעומדת לצאת לפרודקשן עם משתמשים אמיתיים
  • יש SLA לזמינות או לזמן תגובה שצריך לוודא שעומדים בו
  • לפני דיפלוי משמעותי, רוצים לוודא שהמערכת עומדת בעומס
  • יש חשד לדליפת זיכרון תחת עומס ממושך

מה אומרים לקלוד

אין פקודות ללמוד. אחרי ההתקנה פשוט כותבים לקלוד משפט כמו:

  • "תבנה בדיקת עומס לפרויקט הזה"
  • "צריך load test עם k6"
  • "תבדוק שהמערכת עומדת ב-500 משתמשים במקביל"
  • "בדיקת עומס לפני שעולים לאוויר"

דוגמה

מה נותנים

"תבנה בדיקות עומס - צפי 200 משתמשים במקביל, זמן תגובה מתחת ל-500ms"

מה מקבלים

תיקיית בדיקות עומס עם שלושה תסריטים מוכנים (רגיל / זינוק / ממושך), חיבור לתסריטי ההרצה של הפרויקט, וסף כשלון מוגדר לפי הדרישה.

מה צריך שיהיה מותקן

מהלמה / הערה
k6בינארי נפרד (לא חבילת npm) - מותקן לפי מערכת ההפעלה: brew / choco / winget / הוראות Grafana הרשמיות

לתשומת לבך: אסור להריץ את בדיקת העומס הממושכת (soak) על סביבת פרודקשן חיה - רק על staging או סביבה מבוקרת.

התקנה בהדבקה אחת

פותחים את Claude Code, מדביקים את הבלוק הבא, והוא מתקין הכול לבד:

הי קלוד! התקן לי בבקשה את הסקיל "בדיקות עומס" (stress-test-setup).
1. זהה את מערכת ההפעלה שלי ואת התיקייה ~/.claude/skills/ (ב-Windows: C:\Users\<user>\.claude\skills\). צור אותה אם אינה קיימת.
2. הורד את החבילה: https://hiyabh.github.io/claude-skills/dl/stress-test-setup.tar.gz
3. חלץ ממנה את התיקייה skills/stress-test-setup אל ~/.claude/skills/stress-test-setup. אם כבר קיים סקיל בשם הזה - שאל אותי לפני שאתה דורס.
4. בדוק אם מותקנים אצלי: k6. אם חסר משהו - תגיד לי בדיוק מה להתקין ותציע להתקין בעצמך.
5. הסבר לי בקצרה איך מפעילים - למשל שאני פשוט אומר: "תבנה בדיקת עומס לפרויקט הזה".
מעדיף טרמינל? (Git Bash / Mac / Linux) 
curl -fsSL https://hiyabh.github.io/claude-skills/install.sh | bash -s -- stress-test-setup

או הורדה ידנית של החבילה וחילוץ אל ~/.claude/skills/.
